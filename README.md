# Good Things Come to Those Who @defer

A Slidev presentation by **Giorgio Galassi**: Angular's `@defer` blocks, triggers, hybrid rendering
(CSR / SSG / SSR), hydration, incremental hydration and event replay.

Migrated from the original Canva deck (52 pages) on 2026-10-26. The pixel-art scenes are exported
from Canva as images in `src/`. Everything else (code, tables, definitions, flows) is rebuilt as
native slides. The speaker notes are carried over verbatim (Italian).

## Getting started

```bash
npm install
npm run dev          # http://localhost:3030
npm run build        # static site in dist/
npm run export       # PDF
```
